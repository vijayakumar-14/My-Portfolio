# 🤖 Vijaya Kumar Portfolio |   

Welcome to my personal portfolio website! This project showcases my journey as a Mechatronics Enthusiast, merging the worlds of mechanical engineering, electronics, and software development to build intelligent systems.

## 🚀 Live Demo
Check out the live site here: [https://vijayakumar-portfolio-2007.vercel.app/](https://vijayakumar-portfolio-2007.vercel.app/)

## 🛠️ Tech Stack
This portfolio was built using modern web technologies to ensure a fast, responsive, and sleek user experience:
* **Frontend:** React.js + TypeScript
* **Styling:** Tailwind CSS + Lucide Icons
* **Hosting:** Vercel
* **Version Control:** GitHub

## ✨ Key Features.
* **Responsive Design:** Optimized for both desktop and mobile viewing.
* **Project Showcase:** Highlights my technical projects and educational background.

## 📂 Project Structure
* `/src`: Contains the main React components and layout logic.
* `/public`: Stores essential assets including my custom neon Mechatronics favicon.

## 🔧 Installation & Setup
If you want to run this project locally:
1. Clone the repository: `git clone https://github.com/vijayakumar-14/My-Portfolio.git`
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
